03 · Usage Rules

How the colors behave

Do

  • Use Signal Indigo for anything a learner should recognize as "World Teachers Academy" — logo, module numbering, links
  • Keep Action Orange rare — one enrol button per screen, not every button
  • Use Growth Teal for progress bars, pass marks, and regional/track tags
  • Default to Ink Navy backgrounds for anything credential-related — certificates, transcripts, accreditation pages
  • Use the 50–100 tints for card backgrounds and hover states, never as text color

Don't

  • Don't use orange for headlines, links, or decoration — it will stop reading as a call to action
  • Don't pair Indigo directly on Teal at full saturation — low contrast, hard to read
  • Don't tint body text with any core color below 700 weight — keep body copy in Navy or Paper white
  • Don't introduce a fifth color without updating this guide first
  • Don't use Orange and Teal as a two-color combination for text — they're both mid-brightness and clash
